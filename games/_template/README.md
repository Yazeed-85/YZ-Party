# قالب لعبة جديدة

لعبة «سباق اللمس» كاملة ومشغّلة، تُستخدم كنقطة بداية: كل ما تحتاجه موجود (الدخول للغرفة، الحالة، النتيجة والخبرة، الانسحاب، الدردشة والصوت).

## خطوات إضافة لعبة
1. انسخ المجلد: `games/_template` ← `games/اسم-لعبتك` (حروف إنجليزية صغيرة وشرطات، وهو معرّف اللعبة `id`).
2. عدّل `index.html`: ثوابت اللعبة، `newState`، دالة الحركة (معاملة `runTransaction` دائماً)، و`render`. لا تعدّل قسم «التشغيل» إلا للضرورة.
3. سجّلها في `shared/games-registry.js`: `{ id, name, icon, desc, min, max, ready: true }`. عدد اللاعبين `min/max` (أو `counts: [2,4]`).
4. الخبرة (اختياري لكنه مُوصى به):
   - `shared/level.js` ← `WEIGHT`: وزن لعبتك (الافتراضي 1.2؛ الألعاب الأصعب أعلى).
   - `shared/xp-engine.js` ← `EV`: خبرة كل حدث، وأرسل الأحداث من لعبتك في `details.ev` (انظر `evBy`).
   - الحدّ الأقصى للخبرة في الجولة الواحدة 1000 (تفرضه قواعد Firebase)، ويحدّد `xpGain` سقفاً أقل بكثير.
5. غلاف البطاقة: ضع `game-covers/اسم-لعبتك.svg` (انظر `game-covers/README.txt`).
6. جرّب بجهازين أو نافذتين.

## قواعد لا تكسرها
- **كل تغيير في الحالة بمعاملة** `runTransaction(gameRef(code), ...)`.
- **المضيف وحده** يستدعي `finishGame` (يسجّل النقاط والخبرة ويعيد الجميع للردهة).
- النتيجة: `makeResult('win' | 'draw' | 'coop-win' | 'coop-lose' | 'team-win', ranking, details)`.
- لا تعرض أخطاء Firebase للاعب: `toast(e.message, 'error')` يُصفّيها تلقائياً ويرسل التقني منها للوحة التحكم.
- ألعاب 3 لاعبين فأكثر: `initGroupExit` بدل `initGameExit`، وللفرق `initTeamExit` (انظر `shared/leave.js`).
- الخبرة تُسجَّل فقط حين تكون الغرفة في حالة `playing` منذ 20 ثانية على الأقل (قواعد Firebase)، فالجولات الأقصر لا تُحتسب.
